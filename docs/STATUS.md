# Статус языка: claw 0.5

Что реально работает в установленной версии. Обновляется в конце каждой итерации.

## Готово

| Возможность | Пример |
|---|---|
| Функции, рекурсия, значения любых типов в параметрах и результатах | `fn add(a Point, b Point) Point { ... }` |
| Все целые | `int` (= `i64`), `i8 i16 i32 u8 u16 u32 u64` |
| Дробные | `f32`, `f64`, `1.5`, `1e3` |
| `bool` и символы | `true`, `'a'` (это `u8`) |
| Явные преобразования | `i32(x)`, `f64(n)`, `u8(c)`, `int(flag)` |
| Переменные и `mut` | `x := 5`, `y i32 = 7`, `mut z := 0` |
| Константы времени компиляции | `const limit = 10 * 2` (в `[limit]int` тоже) |
| Структуры, поля, запись в поля | `type P { x int, y int }`, `P{1, 2}`, `p.x = 5` |
| Массивы фиксированного размера | `[4]int`, `[1, 2, 3]`, `[0...]`, `a[i]`, `len(a)`, вложенные |
| Варианты | `type S = Circle{r f64} \| Dot` |
| `match` с проверкой полноты | варианты, целые, символы, `bool`, `_:` |
| Значение может отсутствовать | `?int`, `none`, `f()?`, `f() else 0`, `f() else { ret }` |
| Функция может вернуть ошибку | `int ! E`, `! E`, `fail X`, `f()?`, `f() else e { ... }` |
| Все формы `for`, включая обход массива | `for x in a`, `for x, i in a`, `for i in 0..n`, `for c`, `for` |
| `print` любого значения и `{выражение}` в строке | `print("p = {p}, {a * 2}")` |
| Падение с `файл:строка:колонка`, код 101 | знаковое переполнение любого размера, деление на ноль, сдвиг, индекс вне массива, преобразование, которое не помещается |
| Беззнаковые заворачиваются | `u8(250) + 10` даёт `4` |
| `?` в `main` | печатает `error: ... at файл:строка:колонка`, код выхода 1 |
| Строгость | всё из 0.1, плюс полнота `match`, запрет игнорировать ошибку, запрет менять массив во время `for`, регистр имён, запрет типов, содержащих сами себя |
| `[]T` | `[1, 2]`, `[]`, `a[i]`, `a[i] = x`, `len`, обход, вложенные, проверка границ |
| `str` | литералы, `"{x}"` как значение, `s[i]`, `s[a..b]`, обход, `== != < <= > >=`, неизменяемые байты |
| Срезы | `a[1..3]`, `a[..2]`, `a[3..]` для `[]T`, `[N]T` и `str`, только чтение, с проверкой границ |
| Три способа передать значение | чтение (по умолчанию), `&T` (менять, вызов `f(&x)`), `own x T` (забрать) |
| Владение и авто-освобождение | память освобождается в конце области на любом пути: конец блока, `ret`, `break`, `continue`, `fail`, `?`; временные значения в конце инструкции |
| Перемещения | на первом потребляющем использовании; использовать после перемещения нельзя; патч `copy(x)` |
| `copy(x)` | глубокая копия для любого типа, кроме типов со своим `drop` |
| Свой `drop(x &T)` | для обычных и шаблонных типов, вызывается компилятором |
| Защита от висячих ссылок | запрет менять массив во время обхода и субъект `match`; запрет перекрытия `&` в одном вызове |
| Стандартная библиотека на Claw | `core` всегда доступен (массивы, строки, `to_int`), `use fs`, `use math` |
| `claw fn` | голые указатели, никаких страховок для них |
| Указатели | `*T`, `&x`, `*p`, `p[i]`, `p.x` сквозь указатель, `p + 1`, `q - p`, сравнения, `none` как нулевой указатель |
| Память | `alloc[T](n)`, `free(p)`, `sizeof[T]()`, `cast[T](x)` |
| `defer` | выполняется при выходе из блока на любом пути: конец, `ret`, `fail`, `?`, `break`, `continue` |
| Вызовы C | `extern fn`, любая функция из libSystem, `*u8` из строкового литерала, вариативные (`snprintf`) |
| Шаблоны функций и структур | `fn max[T](a T, b T) T`, `type Pair[A, B] {...}`, типы выводятся или пишутся явно |
| Модули | `use lib.geo`, `pub`, `geo.area(p)`, поиск функции по модулю типа первого аргумента |
| `claw fmt`, `claw fmt --check` | один формат без настроек, комментарии сохраняются; файл не изменится, если поменялось что-то кроме пробелов |
| Свой бэкенд | ARM64, Mach-O, подпись, сегмент `__DATA`, без `as`, `ld`, `clang` |
| Вывод | буфер, одна запись на `print`, короткие записи дописываются |
| `need` | проверяется в месте вызова; ошибка показывает строку вызова и значения переменных |
| `sure` в подписи | проверяется при каждом возврате значения; `ret`, `old(x)` |
| `sure` в теле | утверждение: `sure x == 1`; показывает значения |
| Точная арифметика в контрактах | `+ - *` целых внутри сравнения считаются в 128 битах и не переполняются |
| Эффекты `+mem`, `+io` | `pub` обязан объявить, приватные выводятся по графу вызовов, ошибка `E0160` с патчем |
| Контракты без последствий | нельзя `&`, перемещение, `?`, блок `else`, эффекты |
| `test "имя" { }` и `claw test` | каждый тест в своём процессе, отчёт только о падениях, лимит 10 с |
| Режим проверки (`claw run`, `claw test`) | все контракты; выход за блок кучи, чтение после `free`, двойной `free`, чужой `free`, нулевой указатель, утечки |

## Частично

| Возможность | Что есть | Чего нет |
|---|---|---|
| Доказательство контрактов | всё проверяется во время работы | доказательства при компиляции и удаления проверок (итерация 6) |
| Контракты с вызовами | работают в `claw run` и `claw test`; `claw build` пишет, сколько их пропущено | проверки в `claw build` |
| Эффекты в `claw fn` | видимые `alloc`, `print` и вызовы проверяются | `extern` принимается на веру; список мест появится с `claw audit` |
| Проверка памяти | куча | стек и статические данные; что делает функция по `extern` |
| Форматирование | команда `claw fmt` | автоматического запуска при сборке |
| Строки `{x}` как значение | работают | длиннее 64 КБ завершаются ошибкой; кавычки внутри `{...}` писать нельзя |
| Рекурсивные типы | через `[]T`: `type Tree { kids []Tree }`, и через указатели в `claw fn` | неявный бокс для `?T`, обещанный в плане |
| Перемещение | только целые локальные переменные | разбора значения на части без копирования (кроме `remove`, `swap`) |
| Печать дробных | до 15 значащих цифр для `f64`, 7 для `f32`, через `snprintf` | точного кратчайшего представления; `3.0` печатается как `3` |
| Патчи в ошибках | показываются и есть в JSON | команды `claw fix` (итерация 7) |
| Отладка | lldb видит имена функций | номера строк (DWARF, итерация 10) |
| Шаблоны | функции и структуры; тело проверяется для каждого использованного набора типов | шаблонных вариантов; неиспользованный шаблон не проверяется вообще |
| Запись для `claw why` | все `alloc`/`free` проходят через две функции рантайма | самой записи и записи вызовов `extern` (итерация 7) |
| Вызовы C | регистры, вариативные аргументы, узкие результаты проверены тестами | невариативные аргументы сверх восьми на стеке написаны по правилам Apple, но подходящей функции в libSystem для теста нет |

## Ещё нет

Все эти конструкции дают понятную ошибку `E0900`.

| Итерация | Возможности |
|---|---|
| 6 | SSA, регистры, инлайнинг, `--fast`, удаление доказанных проверок |
| 7 | `claw test` с фаззером, `claw why`, `claw fix`, вычисления при компиляции |
| 8 | `claw card/sig/ctx/audit`, бенчмарк токенов, экзамен для Haiku |
| 9 | компилятор на самом Claw |
| 10 | DWARF, Linux, x86-64, SIMD, параллельность, LSP |

Не в роадмапе, но обещано в плане: функция как значение (`fn(int) int`).

## Известные ограничения 0.5

- В `claw build` обращение по нулевому или висячему указателю падает как в C (код 139) или портит память. `claw run` ловит это для кучи и нулевого адреса.
- `/`, `%` и сдвиги в контрактах считаются как обычно и могут упасть. Умножение значений шире 64 бит в контракте завершается сообщением, а не даёт неверный ответ.
- Пока идёт контракт с вызовами, контракты с вызовами внутри него отключены, иначе `sure ret == sum(a)` не закончился бы.
- `old(x)` запоминает только числа и `bool`; для массива пишите `old(len(a))`.
- Подключается только libSystem; своих `.o` и других библиотек пока нет.
- Глубокая рекурсия заканчивается обычным падением по стеку (код 139), без понятного сообщения.
- Функция: не больше примерно 1 МБ машинного кода и 7 МБ локальных данных, иначе `E0901`. Большие данные надо класть в `[]T`.
- Весь `core` компилируется в каждую программу: неиспользованный код пока не выбрасывается.
- Литерал `[x...]` заполняется простым циклом.
- Ошибка внутри `{...}` в строке указывает на начало всей строки.
- Код намеренно наивный: каждая переменная лежит в памяти. Ускорение запланировано на итерацию 6.
