# Статус языка: claw 0.1

Что реально работает в установленной версии. Обновляется в конце каждой итерации.

## Готово

| Возможность | Пример |
|---|---|
| Функции, параметры, возврат значения, рекурсия | `fn add(a int, b int) int { ret a + b }` |
| `main` без аргументов и результата | `fn main() { ... }` |
| Типы `int` (64 бита) и `bool` | `x int = 5` |
| Переменные: неизменяемые и `mut` | `x := 5`, `mut y := 0` |
| Присваивание и составные операторы | `y = 1`, `y += 2`, `y <<= 1` |
| Отбрасывание результата | `_ = f()` |
| `if`, `else if`, `else` | `if a > 0 { ... } else { ... }` |
| Три формы `for`, `break`, `continue` | `for i in 0..10`, `for x > 0`, `for { }` |
| Арифметика и биты | `+ - * / % & \| ^ ~ << >>` |
| Сравнения и логика с коротким замыканием | `== != < <= > >=`, `and or not` |
| Литералы | `1_000`, `0xff`, `0b101`, `true` |
| `print` одного числа, bool или строкового литерала | `print(x)`, `print("Hello")` |
| Падение при знаковом переполнении, делении на ноль, неверном сдвиге | `trap: integer overflow at f.claw:3:5`, код 101 |
| Правило переноса строк | строка, оканчивающаяся оператором, продолжается |
| Строгость | неиспользуемое, перекрытие имён, `mut` без изменений, недостижимый код, нет `ret`, игнор результата: всё ошибки |
| Формат ошибок | `f.claw:2:9 E0105 ...; fix: ...`, флаг `--json`, у части ошибок есть патч |
| Команды | `claw run`, `claw build [-o]`, `claw check`, `claw --version`, `--emit-cir` |
| Свой ARM64-кодогенератор, запись Mach-O, ad-hoc подпись, SHA-256 | работает с пустым `PATH`, без `as`, `ld`, `clang` |

## Частично

| Возможность | Что есть | Чего нет |
|---|---|---|
| Строки | литерал прямо внутри `print` | переменные типа `str`, `{x}` внутри строки |
| Патчи в ошибках | показываются и есть в JSON | команды `claw fix` |
| Отладка | lldb видит имена функций | номера строк (DWARF, итерация 10) |
| Вывод | один `write` на `print` | обработка частичной записи |

## Ещё нет

Все эти конструкции уже зарезервированы и дают понятную ошибку `E0900`, а не странный сбой разбора.

| Итерация | Возможности |
|---|---|
| 2 | остальные числа, `f64`, структуры, `[N]T`, варианты, `match`, `?T`, `T ! E`, `fail`, `?`, `else` на значении, `{x}` в `print`, форматтер; разбор `need/sure/+effects` |
| 3 | `claw fn`, указатели, `alloc/free`, `defer`, `extern`, шаблоны, модули `use`/`pub` |
| 4 | `[]T`, `str`, `own`, `&`, автоматическое освобождение, `drop`, стандартная библиотека |
| 5 | проверка `need/sure`, эффектов, блоки `test`, ASan для Когтя |
| 6 | SSA, регистры, инлайнинг, `--fast`, удаление доказанных проверок |
| 7 | `claw test` с фаззером, `claw why`, `claw fix`, вычисления при компиляции |
| 8 | `claw card/sig/ctx/audit`, бенчмарк токенов, экзамен для Haiku |
| 9 | компилятор на самом Claw |
| 10 | DWARF, Linux, x86-64, SIMD, параллельность, LSP |

## Известные ограничения 0.1

- Глубокая рекурсия заканчивается обычным падением по стеку (код 139), без понятного сообщения.
- Функция больше примерно 1 МБ машинного кода даёт ошибку `E0901`.
- Код намеренно наивный: каждая переменная лежит в памяти. Ускорение запланировано на итерацию 6.
