# Claw: материалы для сайта

Это не промпт, а справка: что такое язык, чем он хорош, что в нём есть и что можно показать. Все примеры
и выводы консоли настоящие (версия 0.10, запущено на этой кодовой базе). Тексты для сайта удобнее держать на английском:
язык, сообщения компилятора и код в примерах английские; здесь пояснения по-русски, а заготовки заголовков по-английски.

## 1. Одной строкой

- **Название:** Claw (от claw'd; «коготь»). Расширение файлов `.claw`, команда `claw`.
- **Что это:** низкоуровневый компилируемый язык, целиком написанный Claude. Исходник превращается в подписанный
  исполняемый файл без LLVM, ассемблера и линкера. Ни рантайма, ни сборщика мусора.
- **Вопрос, на который он отвечает:** «Какой системный язык нужен, если код пишет ИИ, а отвечает за него человек?»
  Почти все новые языки отвечают на вопрос «как сделать C получше». Этот отвечает на другой.
- **Заготовки заголовка:**
  - *The systems language designed for code written by AI and answered for by humans.*
  - *Small enough to fit in a prompt. Strict enough to trust.*
  - *C-level control. A compiler that writes your tests and explains your crashes.*
- **Для кого:** разработчики на C, C++, Rust, Zig, которым интересно, как должен выглядеть язык в эпоху,
  когда значительную часть кода пишут модели; исследователи и энтузиасты языков и компиляторов; все, кто делает
  агентов, которые пишут и чинят код.

## 2. Главные плюсы (по убыванию «вау»)

Каждый пункт: формулировка для сайта и то, чем она подтверждена.

1. **Весь язык помещается в промпт.** Полный справочник (`claw card`) короче 2500 токенов; модель, которая никогда не видела
   Claw, пишет на нём по одной этой странице. *Подтверждение:* экзамен, в котором Claude Haiku писал программы только по
   карточке, одна попытка на программу: 19 из 24 на первом раунде и 11 из 12 на новом наборе после правки карточки.
   (Маленькая выборка, задачи писал автор языка: так и говорить.)
2. **Компилятор пишет тесты за вас.** `claw test` без единого написанного теста бьёт по всем функциям без побочных эффектов:
   граничные значения, случайные входы и входы, подобранные по покрытию кода. Падение сокращается до минимального примера.
3. **Не «где упало», а «почему».** `claw why` показывает только строки, которые повлияли на ошибку, и значения на них.
4. **Контракты `need` / `sure`.** Одновременно документация, проверка, тест и подсказка оптимизатору. Что компилятор может
   доказать, он убирает (код быстрее); остальное проверяет и не молчит об этом.
5. **Лапа и Коготь: две передачи в одном языке.** `fn` безопасен: нет указателей и `free`, память освобождается
   сама в конце области видимости, сборщика нет. `claw fn` это обычный C: указатели, `alloc`/`free`, `defer`.
   `claw audit` показывает все места, где компилятор верит вам на слово.
6. **Подпись говорит правду.** `+mem` (выделяет память) и `+io` (трогает внешний мир); нет плюсов, значит это гарантия.
   Читателю, человеку или модели, не нужно открывать тело функции.
7. **Считаем токены всего цикла:** написать, прочитать, исправить. Короткие обычные английские слова в роли ключевых
   (их 28), нет `;`, один формат кода (`claw fmt`), сообщения об ошибках по 30-45 токенов с готовым патчем (`claw fix`).
8. **От исходника до бинарника только наш код.** Свой кодировщик ARM64 и x86-64, свой писатель Mach-O и ELF, своя
   подпись (SHA-256 написан тоже здесь). Компилятор есть и на Rust (без единой внешней зависимости), и на самом Claw: он
   собирает сам себя до неподвижной точки.
9. **Скорость почти как у C.** Не «обещаем», а замерено (раздел 5).

## 3. Что есть в языке

Перечень для страницы «Features» (всё работает в 0.12):

- **Типы:** `int` (64 бита), `i8 i16 i32 u8 u16 u32 u64`, `f32 f64`, `bool`, `str`, структуры, варианты (`type Shape = Circle{r f64} | Dot`),
  массивы `[N]T`, динамические `[]T`, `?T` (значение может отсутствовать), `T ! E` (может вернуть ошибку).
- **Проверенная арифметика:** знаковое переполнение, деление на ноль, выход за массив, плохой сдвиг: падение с
  `файл:строка:колонка` и кодом 101. Беззнаковые числа заворачиваются, как в C.
- **`match` с проверкой полноты**, ошибки как значения (`fail`, `?`, `else`), без исключений и без `null`.
- **Автоматическая память:** владение (`own`), чтение по умолчанию, изменение через `&`, явное `copy`. Висячих ссылок
  негде взять, утечек нет, гонок нет.
- **Коготь:** указатели, `alloc`/`free`, `defer`, вызов любых C-функций (`extern fn`), `cast`, `sizeof`.
- **Шаблоны** (`fn max[T]`, `type Pair[A, B]`), модули (`use`), хеш-таблица и строковые функции в стандартной библиотеке,
  функции как значения (`fn(int) int`).
- **Вычисления при компиляции:** `const big int = twice(limit)` исполняется во время сборки.
- **Потоки без гонок, в стиле Claw:** `par.map(xs, f)` и `par.build(n, f)` делят работу между ядрами, общей памяти нет, ответ всегда
  такой же, как у обычного цикла; `par.spawn(work, x)` / `par.join(t)` для одной отдельной задачи.
- **Сишные библиотеки без ручных объявлений:** `use c "zlib.h"` и `link "z"`; проверено на libc, zlib, sqlite3 и своей библиотеке;
  колбэки в C: `cast[*u8](f)`; структуры до 16 байт передаются и возвращаются по значению; несуществующий C-символ находит сборка, а не запуск.
- **Скрипты и пакеты:** `claw f.claw args` (и `#!/usr/bin/env claw`), `os.args()`, пакеты `claw.pkg` с замком `claw.lock` (SHA-256 дерева).
- **SIMD вручную:** `f64x2`, `f32x4`, `i32x4` с `vload`, `vstore`, `lane`, `fma` (NEON на arm64, SSE на x86-64).
- **Режимы сборки:** `claw run` (все проверки и ловля ошибок памяти: чтение после `free`, двойной `free`, утечки),
  `claw build` (оптимизации, остаются только недоказанные проверки), `claw build --fast` (все проверки сняты, риск как в C).
- **Инструменты в самом компиляторе:** `run`, `build`, `test`, `why`, `fix`, `check`, `fmt`, `sig`, `ctx`, `audit`,
  `card`, `lsp` (подсказки и ошибки в редакторе), `-g` (lldb останавливается на строках исходника).
- **Цели:** macOS arm64, macOS x86-64, ARM64 Linux.
- **Оптимизатор:** SSA, инлайнинг, свёртка констант, устранение повторов, вынос из циклов, распределение регистров,
  удаление проверок, которые компилятор доказал лишними.

## 4. Что можно показать

Готовые «экраны» для сайта. Все выводы настоящие.

### 4.1 Главный экран: контракт и причина падения

```claw
fn avg(xs []int) int
    need len(xs) > 0
{
    mut total := 0
    for x in xs { total += x }
    ret total / len(xs)
}

fn main() {
    print(avg([4, 8, 15]))
    print(avg([]))
}
```

```
$ claw run avg.claw
9
trap: need failed: `len(xs) > 0` in avg at avg.claw:11:11
  left = 0
  xs = []

$ claw why avg.claw
FAIL need failed: `len(xs) > 0` in avg at avg.claw:11:11
why    avg.claw:2  need len(xs) > 0
       avg.claw:11  print(avg([]))    left = 0, xs = []
```

Подпись: «Не адрес и стек, а три строки: что нарушено, где и с какими значениями».

### 4.2 Тесты, которые написал компилятор

```claw
fn pick(xs []int, i int) int {
    ret xs[i]
}
```

```
$ claw test pick.claw
FAIL pick: index out of bounds at pick.claw:2:9
  input  pick([], 0)
  why    pick.claw:1  fn pick(xs []int, i int) int {    i = 0
         pick.claw:2  ret xs[i]    index = 0, len = 0
  fix    add `need i >= 0 and i < len(xs)` to pick
auto: 1 functions, 1 inputs, 1 failed
```

Ни одного теста не написано; найден минимальный вход, причина и готовое исправление.

### 4.3 Ошибка с готовым исправлением

```claw
fn main() {
    a []int = [1, 2, 3]
    b := a
    print(len(a) + len(b))
}
```

```
$ claw check move.claw
move.claw:4:15 E0151 `a` was moved away at line 3; fix: write `copy(a)` there
$ claw fix move.claw
fixed 1
```

После `claw fix` строка становится `b := copy(a)`. Другие настоящие сообщения:

```
imm.claw:3:21 E0103 `count` cannot change; fix: declare `mut count`
miss.claw:4:5 E0120 `match` misses: Dot
```

Сравнение для сайта: сообщения об одной и той же ошибке в сумме занимают 288 токенов у Claw, 651 у clang и 1343 у rustc.

### 4.4 Память без сборщика и без `free`

```claw
fn pets() []str {
    mut a []str = []
    push(&a, "cat")
    push(&a, "dog")
    push(&a, "bird")
    ret a                    // отдаём, копии нет
}

fn main() {
    a := pets()
    b := copy(a)             // копия всегда явная
    print("{len(a)} {len(b)}")
    print(join(a, " "))
}                            // a и b освобождаются здесь
```

Вывод: `3 3` и `cat dog bird`. Сравнить с C (`malloc`/`free` вручную) и Python (нужен сборщик).

### 4.5 Одна программа: безопасная Лапа и Коготь на C

```claw
extern fn strlen(s *u8) u64

claw fn sum3() int {
    p := alloc[int](3)
    defer free(p)
    p[0] = 1
    p[1] = 2
    q := p + 2
    *q = 3
    ret p[0] + p[1] + p[2]
}

claw fn length_of_hi() u64 {
    ret strlen("hi")
}

fn main() {
    print(sum3())            // безопасный код зовёт Коготь
    print(length_of_hi())
}
```

```
$ claw audit paw_and_claw.claw
extern   paw_and_claw.claw:4  strlen  effects taken on trust
claw fn  paw_and_claw.claw:6  sum3  alloc free index arith deref
claw fn  paw_and_claw.claw:16  length_of_hi  extern
audit: 2 claw fn, 1 extern, 0 checks not in `claw build`; std has 17 claw fn, not listed
```

Идея экрана: «опасное видно и ищется командой».

### 4.6 SIMD и потоки

```claw
claw fn dot(a *f64, b *f64, n int) f64 {
    mut acc := f64x2(0.0)
    mut i := 0
    for i + 2 <= n {
        acc = fma(vload(a + i), vload(b + i), acc)
        i += 2
    }
    ret lane(acc, 0) + lane(acc, 1)
}
```

```claw
use par

fn total(own xs []int) int {
    mut s := 0
    for x in xs { s += x }
    ret s
}

fn main() {
    // ... a и b: два массива по 50 чисел
    ta := par.spawn(total, a)
    tb := par.spawn(total, b)
    print(par.join(ta) + par.join(tb))     // 4950
}
```

Мысль: гонок данных нет по построению, а не «по аккуратности». Полные версии лежат в `examples/`.

## 5. Цифры (замерено на одном Mac с Apple Silicon)

**Скорость программ**, медиана из 5 запусков, отношение к `clang -O2` (1.0x это столько же; в Claw остаются
проверки, которые компилятор не смог доказать лишними):

| Тест | clang -O2 | Claw | Claw / clang -O2 |
|---|---|---|---|
| primes | 0.189 с | 0.189 с | 1.0x |
| sieve | 0.091 с | 0.098 с | 1.1x |
| matmul_simd (SIMD вручную) | 0.130 с | 0.144 с | 1.1x |
| mandel | 0.103 с | 0.139 с | 1.4x |
| collatz | 0.198 с | 0.286 с | 1.4x |
| fib(40) | 0.150 с | 0.289 с | 1.9x |
| matmul (без SIMD) | 0.129 с | 0.366 с | 2.8x |

Не говорить «быстрее C»: на одних задачах равны, на других отстаём почти в 3 раза. Правильная формулировка: «на уровне C на
типичных задачах, с включёнными проверками».

**Скорость компиляции:** около 320 000 строк в секунду до подписанного бинарника (44 000 строк за 137 мс).

**Токены** (оценка двумя правилами подсчёта, а не настоящим токенизатором; 21 небольшая задача, у всех трёх языков вывод
программ одинаков):

- Claw против C: на 37.9% короче; против Rust: на 17.8% короче.
- Сообщения об ошибках для одной ошибки: Claw 288 токенов, clang 651, rustc 1343 (всего по 8 типовым ошибкам).

**Размер:** компилятор на Rust около 25 000 строк без внешних зависимостей; тот же компилятор на самом Claw около
15 000 строк; стандартная библиотека меньше 900 строк; почти 2500 автоматических тестов.

## 6. Как попробовать

Нужны macOS на Apple Silicon и Rust.

```bash
cargo build --release --manifest-path compiler/Cargo.toml
python3 tools/install.py
claw run examples/tour.claw
```

Семь коротких программ в `examples/`: `tour` (обзор языка), `contracts`, `ownership`, `paw_and_claw`, `simd_dot`,
`threads`, `generics`. Полный справочник языка: `claw card`.

## 8. Честно о границах (одним абзацем, чтобы не обещать лишнего)

Язык молодой, версия 0.12. Основная платформа macOS на Apple Silicon. Цель x86-64 проверена через Rosetta, а не на реальном
Intel; Linux проверен в виртуальной машине с musl. Автоматической векторизации циклов нет, SIMD пишется вручную.
Пакеты: папки и git-адреса с замком, без реестра. Нет Windows, WebAssembly и Linux на x86-64. Компилятор на самом Claw покрывает основное подмножество, но не потоки, SIMD, сишные заголовки, пакеты, Linux и инструменты
`test`, `why`, `fix`. Лицензия пока не выбрана.
