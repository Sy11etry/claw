§ 01

The question

How do we make C a little better?

What should a systems language look like when a model writes the code and a human has to answer for it?

Almost every new language asks the first question. Claw is an answer to the second one. Every feature on this page was checked against eight principles, and each had to pay for its place.

    § 03

    Two gears

    Paw is safe. Claw is C.

    Paw · fn

    Claw · claw fn

    ⟷

    Paw: fn

    No pointers and no free. Values move, & lends them, copy is always explicit, and everything is released at the end of its scope. No garbage collector, no runtime. No dangling references to be had, no leaks, no data races.

    Claw: claw fn

    Plain C, on purpose: raw pointers, alloc / free, defer, cast, any C function through extern. Arithmetic and bounds stay checked; pointers don’t. claw audit lists every place the compiler takes your word for it.

      § 05

      Signatures & contracts

      The signature tells the truth.

      +mem allocates. +io touches the world. No plus is a guarantee, so a reader, human or model, never has to open the body. These three lines are what claw sig pets.claw prints.

      • fn total(xs []int) intpure: no allocation, no I/O, fair game for claw test
      • fn pets() []str +memallocates; still no I/O
      • fn main() +mem +ioeffects worked out by the compiler, not written by hand

      A contract — need and sure — is four things at once

      1. DocumentationWhat the function asks for and what it promises, in the signature.
      2. A checkRun at every call and every return. Never silently skipped.
      3. A test oracleclaw test knows which generated inputs are fair.
      4. A hintWhat the compiler proves, it removes: avg keeps 2 of 4 checks.

        § 09

        The fine print, in large print

        Claw is young: version 0.10. The main platform is macOS on Apple Silicon. The x86-64 target is tested under Rosetta, not on real Intel hardware; Linux is tested in a VM with musl. Loops are not vectorized for you; SIMD is written by hand. There is no package manager. The self-hosted compiler covers the core language, but not threads, SIMD, Linux, or test, why and fix. A license has not been chosen yet.
