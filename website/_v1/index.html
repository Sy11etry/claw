The question

Almost every new language asks how to make C a little better. Claw asks something else: what should a systems language look like when a model writes the code and a human has to answer for it?

02Paw & Claw

      
Two gears.
One language.

    


    

      
      
      
    


    

      

        

          
Safe by construction.

          
fn has no pointers and no free. Values move, & lends them, copy is
            always explicit, and everything is released at the end of its scope. No garbage collector, no runtime.

          
    
            
  • No dangling references to be had
    • 
            
  • No leaks
    • 
            
  • No data races
    • 
          

        

        

          
Plain C, on purpose.

          
claw fn is C: raw pointers, alloc / free, defer, cast, and any C
            function through extern. Arithmetic and bounds stay checked; pointers don’t.

          
And claw audit lists every place the compiler takes your word for it.

        

        
On this page, orange means what it means to the compiler: trust.

claw test

        
Tests nobody wrote.

        
Every function without +io gets hit with boundary values, random inputs and inputs chosen for code
          coverage. A failure shrinks to the smallest example that still breaks.

        
How shrinking works, in a picture:

        

          pick([-38, 12, 99], 7)pick([12], 3)pick([], 1)pick([], 0)
        

      

      

        
claw why

        
The cause, not the address.

        
Only the lines that led to the failure, with the values they held. No hex, no stack of frames to walk by hand.

      

      

        
claw fix

        
Patches, not essays.

        
Errors run 30–45 tokens and carry a ready patch with a stable code. claw fix applies the safe ones.

      

    

  







  

    

      
04Signatures & contracts

      
The signature
tells the truth.

      
+mem allocates. +io touches the world. No plus is a guarantee, so a reader, human or
        model, never has to open the body.

    


    

      

        fn total(xs []int) int
        guaranteed pure
      

      

        fn pets() []str +mem
        allocates
      

      

        fn main() +mem +io
        allocates · touches the world
      

      
$ claw sig pets.claw

    


    

      

        
Contracts are four things at once.

        
need and sure are documentation, a run-time check, a test oracle and an
          optimizer hint. What the compiler can prove, it removes and the code gets faster. The rest it checks, out loud.
          Never silently.

    08Everything in 0.10
    
      
    The spec sheet.
    
    
    
    
    
  
    

    



    
  
    
    
    Honest edges
    
    
    
      Claw is young: version 0.10. The main platform is macOS on Apple Silicon. The x86-64 target is tested under Rosetta,
      not on real Intel hardware; Linux is tested in a VM with musl. Loops are not vectorized for you; SIMD is written by
      hand. There is no package manager. The self-hosted compiler covers the core language, but not threads, SIMD, Linux,
      or test, why and fix. A license has not been chosen yet.
