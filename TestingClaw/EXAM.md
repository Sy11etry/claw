## Что это значит для карточки

Все четыре падения сводятся к одному правилу, которого в карточке нет: читаемый параметр нельзя вернуть без `copy`. Для чисел это работает само (`ret x` для `int`), а для `str`, `[]T` и полей структур нет. Модель, которая прочла карточку, не видит этого правила и пишет `ret s`. Одна строка в карточке, например «параметр только читается: вернуть его можно через `copy(p)`», закрыла бы все четыре падения. Карточка сейчас 1999 из 2000 токенов, поэтому строку надо выкупить из другого места.
